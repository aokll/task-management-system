# JavaRush Task Tracker (Stage 5: Security)

Проект дополнен системой аутентификации и авторизации.

### Новые возможности:
*   **Spring Security 6:** Доступ ко всем ресурсам ограничен.
*   **BCrypt:** Пароли хранятся в виде защищенных хешей.
*   **Persistence:** Данные пользователей и роли хранятся в PostgreSQL.

### Как запустить:
1. Выполните сборку: `./mvnw clean package`
2. Запустите контейнеры: `docker-compose up --build`
