# Java Task Tracker 

Это учебный проект полнофункционального трекера задач. Приложение помогает структурировать обучение, отслеживать прогресс по уровням и темам.

## Технологии
* **Java 17**
* **Spring Boot 3.x**
* **PostgreSQL**
* **Lombok** 
* **Thymeleaf**
* **Jakarta Validation**

---

##  2 этап разработки

### Слой данных и бизнес-логика
На этом этапе приложение превратилось из «пустышки» в рабочую систему:
* **Entity (`Task`)**: Описана модель задачи с полями: `id`, `title`, `level`, `topic`, `status`, `difficulty`. Добавлена автоматическая фиксация времени создания (`@CreationTimestamp`).
* **Repository (`TaskRepository`)**: Реализованы «умные» методы поиска Spring Data JPA (поиск по части заголовка без учета регистра, фильтрация по теме и статусу).
* **Controller (`TaskController`)**: Создан REST-интерфейс для управления задачами.
* **Validation**: Добавлены правила проверки данных (например, название не может быть короче 3 символов, а уровень не может быть выше 40).
* **Database**: Настроена автоматическая инициализация базы данных.

---

##  Как запустить

1. Убедитесь, что у вас установлен **PostgreSQL**.
2. Создайте базу данных вручную или доверьтесь авто-созданию в приложении.
3. Склонируйте репозиторий.
4. Запустите проект через IntelliJ IDEA (кнопка Run в `DemoApplication`).

##  API Эндпоинты (Примеры)

* **Добавить задачу:**  
  `GET /api/tasks/add?title=SpringData&level=15&topic=JPA`
* **Список всех задач:**  
  `GET /api/tasks/all`
* **Поиск по названию:**  
  `GET /api/tasks/search?title=spring`
* **Удаление:**  
  `GET /api/tasks/delete?id=1`
