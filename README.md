# Java Task Tracker (Multi-user Edition)

Персональный трекер задач на языке Java, построенный на стеке **Spring Boot + PostgreSQL**.
Приложение поддерживает полноценную регистрацию и гарантирует, что каждый пользователь работает только
со своим списком задач.

---

## Технологический стек

*   **Backend:** Java 17, Spring Boot 3 (Data JPA, Security, Web, Validation)
*   **Database:** PostgreSQL (реляционная база данных)
*   **Security:** Spring Security (шифрование паролей через BCrypt)
*   **Frontend:** Thymeleaf + Bootstrap 5 (адаптивная верстка)
*   **Utils:** Lombok, Maven

---

## Требования

*   **Java:** 17+
*   **Maven:** 3.6+
*   **PostgreSQL:** 14+

---

## Основные функции

1.  **Архитектура DTO & Mappers:** Полное разделение слоя базы данных и слоя представления для максимальной безопасности и гибкости.
2.  **Изоляция данных (Multi-user Logic):** Пользователи не могут видеть или удалять задачи друг друга.
3.  **Админ-панель:** Защищенный раздел для управления пользователями с поддержкой каскадного удаления данных.
4.  **Умный Dashboard:** Расчет прогресса в реальном времени и динамическая индикация сложности.

---

### Что было добавлено на 9 этапе:

*   **Слой DTO (`TaskDto`):** Внедрен объект передачи данных, исключающий прямую передачу сущностей БД на фронтенд.
*   **Компонент Mapper (`TaskMapper`):** Реализован механизм преобразования Entities в DTO, инкапсулирующий логику трансформации типов.
*   **Интеграция Enum в UI:** Форма создания задач теперь поддерживает динамический выбор сложности (`Difficulty`) напрямую из Java-перечислений.
*   **Refactoring:** Перевод бизнес-логики сервисов на работу с DTO-моделями.

## Инструкция по проверке (Этап 9)

#### 1. Тест «Сложности» (Новинка этапа)
*   **Действие:** Зайди на Dashboard, заполни форму новой задачи. В выпадающем списке выбери **HARD**.
*   **Результат:** Ты должен увидеть красный бейдж **HARD** на карточке.
*   **Молекулярный смысл:** Подтверждает, что цепочка `HTML (select) -> Controller (@RequestParam) -> Service (addTask) -> Entity -> DB` пройдена успешно.

#### 2. Тест «Прогресс-бара» (DTO в деле)
*   **Действие:** Отметь задачу как **DONE**.
*   **Результат:** Процент в прогресс-баре должен пересчитаться мгновенно.
*   **Молекулярный смысл:** Подтверждает, что метод `calculateProgress` корректно работает с типом `TaskDto` и правильно фильтрует строковые значения статуса.

#### 3. Тест «Безопасности данных» (Главная фишка DTO)
*   **Действие:** Создай задачу и нажми правой кнопкой мыши -> «Просмотреть код» на карточке.
*   **Результат:** В HTML-коде присутствует только текстовое поле `ownerName`.
*   **Молекулярный смысл:** Мы убеждаемся, что тяжелый объект `User` (с паролем и ролями) не «утек» в браузер, а маппер успешно отсек чувствительную информацию.

#### 4. Тест «Сортировки по уровню»
*   **Действие:** Добавь две задачи с уровнями 5 и 20.
*   **Результат:** Задачи должны отобразиться в списке в строгом порядке согласно уровню.
*   **Молекулярный смысл:** Проверка того, что логика сортировки в `TaskServiceImpl` отрабатывает корректно до этапа трансформации данных в DTO.

## Запуск проекта

1.  **База данных:** Создайте базу в PostgreSQL: `CREATE DATABASE javarush_tracker;`
2.  **Настройки:** Укажите логин и пароль в `src/main/resources/application.yaml`.
3.  **Запуск:** Запустите основной класс `DemoApplication`.
