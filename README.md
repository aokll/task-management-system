# Java Task Tracker (Multi-user Edition)

Персональный трекер задач на языке Java, построенный на стеке **Spring Boot + PostgreSQL**. 
Приложение поддерживает полноценную регистрацию и гарантирует, что каждый пользователь работает только 
со своим списком задач.

---

## Технологический стек

*   **Backend:** Java 17, Spring Boot 3 (Data JPA, Security, Web, Validation)
*   **Database:** PostgreSQL (реляционная база данных)
*   **Security:** Spring Security (шифрование паролей через BCrypt)
*   **Frontend:** Thymeleaf + Bootstrap 5 (адаптивная верстка)
*   **Utils:** Lombok, Maven

---
## Требования

*  Java 17+;
* Maven 3.6+;
* PostgreSQL 14+.
---

## Основные функции

1.  **Система регистрации и входа:**
   *   Безопасное хранение паролей в хешированном виде.
   *   Автоматическое назначение ролей (`USER`).
2.  **Изоляция данных (Multi-user Logic):**
   *   Пользователи не могут видеть или удалять задачи друг друга.
   *   Автоматическая привязка новых задач к текущему авторизованному аккаунту.
3.  **Умный Dashboard:**
   *   Динамический расчет прогресса обучения (в процентах).
   *   Цветовая индикация сложности задач (EASY, MEDIUM, HARD).
   *   Удобное управление: добавление, удаление и отметка "Готово" в один клик.
4.  **Валидация:**
   *   Контроль ввода: названия от 3 до 50 символов, уровни строго 0–40.
5. **Статус API**
   *  Приложение поддерживает не только Web-интерфейс, но и REST API для внешних запросов.

---

### Что было добавлено на 7 этапе: 

*   **Безопасность:** Интегрирован `BCryptPasswordEncoder` для защиты паролей.
*   **Регистрация:** Создан `RegistrationController` и HTML-форма для создания новых аккаунтов.
*   **Multi-tenancy:** Внедрена логика `owner_id`. Теперь база данных фильтрует задачи, показывая пользователю только его записи.
*   **UI:** Добавлен полноценный Dashboard с прогресс-баром и формой быстрого добавления задач.

## Структура проекта

*   `entity/` — описание таблиц БД (User, Task).
*   `repository/` — интерфейсы для работы с БД через Spring Data JPA.
*   `service/` — бизнес-логика (расчет прогресса, фильтрация по владельцу).
*   `controller/` — обработка запросов (Web UI и REST API).
*   `config/` — настройки безопасности и конфигурация системы.

## Запуск проекта

1.  **База данных:** Создайте базу данных в PostgreSQL:
    ```sql
    CREATE DATABASE javarush_tracker;
    ```
2.  **Настройки:** Укажите ваш логин и пароль от PostgreSQL в файле `src/main/resources/application.yaml`:
    ```yaml
    spring:
      datasource:
        url: jdbc:postgresql://localhost:5432/javarush_tracker
        username: ваш_логин
        password: ваш_пароль
    ```
3.  **Запуск:** Запустите основной класс приложения.
4.  **Доступ:** Перейдите по адресу `http://localhost:8080/register` для создания аккаунта.

---

## Проверка:

1. Перейдите по адресу `http://localhost:8080/register` для создания аккаунта;
2. Создайте аккаунт Tester;
3. Перейдите под своей админкой к себе на страницу и создайте какую нибудь задачу;
4. Перейдите по адресу `http://localhost:8080/logout` и войдите в аккаунт пользователя Tester;
5. Если войдя в аккаунт там будет пусто значит проверка прошла успешно.
