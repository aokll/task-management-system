# Java Task Tracker (Stage 3: Docker & UI)

Приложение полностью переведено на контейнерную архитектуру и получило современный веб-интерфейс.

## Что нового на 3 этапе
* **Docker & Docker Compose**: Приложение и база данных теперь полностью изолированы. 
* Запуск всей системы происходит одной командой, без необходимости устанавливать Java или PostgreSQL локально.
* **Full-stack UI**: Реализован пользовательский интерфейс "Java Path" на **Thymeleaf + CSS**.
* **Persistence**: Использование Docker Volumes гарантирует, что ваши задачи не пропадут после остановки или удаления контейнеров.
* **Порты**: Настроена гибкая система проброса портов для избежания конфликтов с локальными сервисами.

---

## Технологический стек
* **Backend:** Java 17, Spring Boot 3, Spring Data JPA.
* **Frontend:** Thymeleaf, HTML5, CSS3.
* **Infrastructure:** Docker, Docker Compose.
* **Database:** PostgreSQL 15.

---

## Архитектура портов

Система использует разделение внутренних и внешних портов для максимальной гибкости:


| Сервис  | Внешний порт (Host) | Внутренний порт (Container) | Описание                                       |
|:--------|:--------------------|:----------------------------|:-----------------------------------------------|
| **App** | `8081`              | `8080`                      | Доступ к веб-интерфейсу в браузере             |
| **DB**  | `5433`              | `5432`                      | Доступ к базе из IDE (IntelliJ Database Tools) |

> **Важно:** Внутри сети Docker приложение общается с базой напрямую по внутреннему порту 
> `5432` через имя сервиса `db`.

## 🚀 Инструкция по управлению проектом

### 1. Первый запуск (Сборка и старт)
Выполните эти команды последовательно из корня проекта:

1. **Сборка приложения (Maven):**
   ```bash
   mvn clean package
   ```
2. **Сборка и запуск контейнеров (Docker):**
   ```bash
   docker-compose up --build
   ```
   *Ключ `--build` обязателен, чтобы Docker подтянул свежий .jar файл.*

### 2. Проверка работоспособности (Check-list)
*   **Логи:** В терминале должна появиться строка `Running with Java 17.x.x...` и `Started DemoApplication`.
*   **UI:** Зайдите на [http://localhost:8081/dashboard](http://localhost:8081/dashboard). Попробуйте добавить задачу.
*   **База:** Проверьте JSON-ответ по адресу [http://localhost:8081/api/tasks/all](http://localhost:8081/api/tasks/all).

### 3. Ключевые команды управления
*   **Остановка:** Нажмите `Ctrl + C` в терминале.
*   **Полная очистка:** `docker-compose down` (удаляет контейнеры и сети).
*   **Удаление данных:** `docker-compose down -v` (стирает все задачи из базы).

## Доступные эндпоинты

### Web UI
* `GET /dashboard` — Главная панель управления задачами.

### API (для Postman/Browser)
* `GET /api/tasks/all` — Получить все задачи в формате JSON.
* `GET /api/tasks/add?title=...&level=...` — Быстрое добавление задачи.
* `GET /api/tasks/delete?id=...` — Удаление задачи по ID.

## Валидация и безопасность
* Приложение блокирует попытки добавить задачи с уровнем выше 40 или пустым названием.
* Реализована базовая индикация текущего пользователя (Admin Mode).
