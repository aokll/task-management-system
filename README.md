# Java Task Tracker (Stage 5: Spring Security & Auth)

Пятый этап разработки переводит приложение на уровень **Enterprise**.
Теперь система защищена механизмом авторизации, а пароли хранятся в зашифрованном виде.

## Новое на 5 этапе: Безопасность

*   **Spring Security 6**: Внедрена система «фильтрации» запросов. Приложение закрыто от неавторизованного доступа.
*   **BCrypt Encryption**: Пароли пользователей никогда не хранятся в открытом виде. Используется адаптивный алгоритм хеширования BCrypt.
*   **Custom UserDetailsService**: Реализована связь Spring Security с нашей базой данных PostgreSQL. Система «узнает» пользователей из таблицы `users`.
*   **Role-Based Access**: Подготовлена база для разделения прав доступа (Роли `USER`, `ADMIN`).
*   **Auto-Provisioning**: При первом запуске система автоматически создает суперпользователя (Admin) для доступа в панель управления.

---

## Технологический стек (Security Layer)
*   **Spring Security**: Конфигурация доступа и защита от атак.
*   **Hibernate ElementCollection**: Для эффективного хранения ролей пользователей в базе.
*   **CommandLineRunner**: Для автоматической инициализации тестовых данных и администратора.

---

## Архитектура защиты

1.  **`SecurityConfig`**: Определяет правила (например, все эндпоинты требуют авторизации).
2.  **`User` (Entity)**: Хранит логин, хэш пароля и статус активности.
3.  **`UserDetailsServiceImpl`**: Ищет пользователя в БД и передает его движку безопасности.
4.  **`BCryptPasswordEncoder`**: Шифрует пароли перед сохранением и проверяет их при входе.
