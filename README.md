# JavaTracker

## Этап 16: Final Release & Infrastructure Deployment (Итоговая сборка и развертывание)

### Описание приложения

**JavaTracker** — это полноценная экосистема для управления задачами (Task Management System), 
вдохновленная процессом обучения на платформе JavaRush. 
Приложение решает проблему контроля личного прогресса разработчика при прохождении сложных уровней и тем.

#### Основной функционал системы:
* **Интерактивный Dashboard** — веб-интерфейс, отображающий список текущих задач пользователя, 
* распределенных по уровням сложности, темам и статусам, с автоматическим расчетом общего процента выполнения.
* **Многопользовательский режим и безопасность** — каждый пользователь видит и управляет
* исключительно своими задачами. Доступ к системе защищен авторизацией, а пароли надежно 
* зашифрованы криптографическим алгоритмом.
* **Асинхронный анализатор задач** — при завершении задачи система имитирует тяжелую фоновую проверку кода. 
* Процесс улетает в изолированный пул потоков, не блокируя работу пользователя с интерфейсом приложения.
* **Админ-панель (RBAC)** — специальный защищенный уровень управления для пользователей с ролью `ADMIN`, 
* позволяющий просматривать полный список зарегистрированных аккаунтов и осуществлять каскадное удаление нарушителей.
* **Открытый REST API** — помимо интерактивного веб-интерфейса, приложение предоставляет 
* полноценный программный интерфейс (API), задокументированный через Swagger, для интеграции с внешними сервисами.

### Стек технологий проекта

#### Полный стек:
* **Java 17/21** — Базовый язык программирования бэкенда.
* **Spring Boot (MVC, Security, Data JPA, Validation)** — Корневой каркас приложения.
* **Thymeleaf & Bootstrap 5** — Технологии UI-слоя для адаптивного веб-интерфейса.
* **PostgreSQL** — Реляционная база данных для хранения пользователей, ролей и задач.
* **Flyway** — Инструмент автоматического версионирования и миграции схем БД.
* **Springdoc-OpenAPI 3 (Swagger)** — Автоматическая интерактивная документация REST API.
* **SLF4J + Logback + MDC** — Архитектура сквозного логирования и аудита безопасности.
* **Java Concurrency & Spring Async** — Асинхронный движок фоновой обработки задач.
* **JUnit 5 & Mockito** — Инфраструктура автоматизированного тестирования.
* **Lombok** — Библиотека для сокращения шаблонного Java-кода.
* **Docker & Docker Compose** — Контейнеризация приложения и всей инфраструктуры.

### Проверка работоспособности кода

Готовое приложение полностью контейнеризировано и разворачивается одной командой, 
без необходимости вручную устанавливать базу данных или настраивать переменные окружения.

#### Порядок локального запуска:
1. Откройте терминал в корневой папке проекта.
2. Выполните команду для сборки и запуска Docker-контейнеров:
   ```bash
   docker compose up --build
   ```
3. Система автоматически запустит многоэтапную сборку (`Multi-stage build`), поднимет изолированную базу данных 
PostgreSQL, применит SQL-миграции Flyway и запустит веб-сервер.

#### Доступные точки входа после старта:
* **Основной веб-интерфейс (Dashboard):** `http://localhost:8081/dashboard`
* **Форма создания аккаунта:** `http://localhost:8081/register`
* **Интерактивный Swagger-интерфейс API:** `http://localhost:8081/swagger`
